# fantasy-football-ai

Repository scaffold for an AI-powered fantasy football analyst.

This repo is intentionally bootstrapped without selecting a runtime, framework, deployment target, or package manager. The goal is to make the project ready for Copilot-assisted planning and implementation while keeping product and technical decisions open.

## Current Status

- Repo onboarding is complete.
- Copilot has repository-specific instructions.
- Product and implementation specs have placeholder templates.
- Implementation and test folders exist as neutral starting points.

## Suggested Workflow

1. Capture the product brief in `specs/product-brief.md`.
2. Track unresolved choices in `specs/open-questions.md`.
3. Define the first implementation slice in `specs/implementation-plan.md`.
4. Ask Copilot to implement only after the relevant spec section is concrete.

## Repository Layout

- `.github/copilot-instructions.md`: Repo-specific instructions for Copilot.
- `.vscode/extensions.json`: Recommended VS Code extensions for Copilot-enabled work.
- `specs/`: Product, planning, and open-question templates.
- `src/`: Placeholder for application code once the stack is chosen.
- `tests/`: Placeholder for validation once the stack is chosen.

## Notes

- No application framework has been selected.
- No package manifest has been created.
- No infrastructure or data-provider decisions have been recorded yet.
