# Specs

Use this directory to turn ideas into implementation-ready slices before code is added.

## Suggested Files

- `product-brief.md`: Problem statement, user value, and core workflows.
- `open-questions.md`: Unresolved product and technical decisions.
- `implementation-plan.md`: The next concrete slice to build.

These files are placeholders, not commitments. Replace or expand them once the project direction is clearer.
